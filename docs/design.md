# 配色设计

八套方案都通过语义颜色角色应用到主窗口、设置、表单和日历。颜色为本项目的 UI 适配，不是某种风格的标准色号。

| 配色 | 主色 |
| --- | --- |
| 夜航绿 | 石墨灰与青柠绿 |
| 美拉德 | 浓咖啡与焦糖金 |
| 莫兰迪 | 雾灰紫与低饱和鼠尾草 |
| 玫瑰暮霭 | 雾玫粉 `#D8B4B6`、珍珠白 `#F7F2EE`、暮色棕 `#A78F88` |
| 赤焰夜幕 | 迷雾黑 `#0A090C`、炽焰红 `#E61A23` |
| 森雾亚麻 | 森雾青 `#7FA69A`、亚麻米 `#E6DCC8`、苔灰绿 `#B5C180` |
| 奶油抹茶 | 奶油白与自然苔绿 |
| 克莱因蓝 | 浓郁群青与冰川青蓝 |

正文、辅助文字和表单检查至少 4.5:1 的颜色对比度。25 pt 以上加粗金额使用大字号标准，检查至少 3:1，以保留指定的炽焰红。实际透明叠加后的可读性还取决于壁纸与不透明度。

美拉德和莫兰迪的风格参考：[色系与搭配说明](https://www.openworld.tv/blog/maillard-color-scheme-guide.html)。图标为本项目原创 SVG；截图由实际 Tk 界面生成，展示同一示例时间和金额。
