薪动 v1.2.0 带来八套配色和更清晰的设置界面。支持月薪折算、工作日历、托盘、透明度和登录自动启动。

- **Windows 10/11 x64**：下载并运行 `SalaryMotivator-1.2.0-win64-setup.exe`，无需另装 Python。
- **Debian / Ubuntu / 麒麟**：下载 `salary-motivator_1.2.0_all.deb`，运行 `sudo apt install ./salary-motivator_1.2.0_all.deb`。
- **源码**：下载源码压缩包，或克隆仓库后运行 `python3 scripts/run.py`。

八套配色：夜航绿、美拉德、莫兰迪、玫瑰暮霭、赤焰夜幕、森雾亚麻、奶油抹茶、克莱因蓝。设置中切换可实时预览，取消恢复原外观，保存后记住选择。

升级前请先退出旧版；工资、日历和开机启动设置会保留。首次安装默认随登录启动，可在设置中关闭。

Linux 需要托盘宿主和合成器才能完整呈现托盘及透明效果；Windows 安装包未代码签名。法定节假日和调休需手动标记。

发布前完成 Linux 计算、主题、真实窗口管理器与托盘回归，以及 Windows 包在独立 Wine 环境中的安装、运行和卸载验证。原生 Windows 桌面效果仍需实机试用。
